## Tools

- `grounding_detect`: Locate one concrete object. Arguments: `{"query":"cup","target_image":0}`. Returns relative boxes, labels, and confidence scores.
- `crop_zoom`: Inspect a region. Arguments: `{"bbox_2d":[226,399,265,464],"target_image":0,"label":"small sign"}`. Returns a crop and its new `target_image` index.
- `depth_measure`: Measure one or more located boxes in one image. Arguments: `{"bboxes_2d":[[226,399,265,464]],"target_image":0}`. Returns `regions` with `bbox_2d` and `depth_m`; smaller depth means nearer.
- `object_count`: Count a concrete category. Arguments: `{"query":"apples","target_image":0}`. Returns only `count`.
- `ocr_read`: Read text or parse a chart with PaddleOCR-VL-1.6. Text example: `{"target_image":0,"bbox_2d":[100,100,900,900],"mode":"text"}`. Chart example: `{"target_image":0,"bbox_2d":[100,100,900,900],"mode":"chart"}`; include axes and legend. Omit `bbox_2d` to process the whole image, or omit `mode` for ordinary text. Returns `text` and `truncated`, without an image or text-region boxes.

An empty detection means this query found no candidates, not that the object is absent. Detected boxes are candidates, not a guaranteed complete or correct inventory. A nonempty result does not establish the total number of objects.
