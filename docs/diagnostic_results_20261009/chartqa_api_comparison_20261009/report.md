# ChartQA：本地底座与新旧 step80 同协议 API 复判

保留规则判对题，所有规则错题进入 API：非数值分支采用 DeepEyesV2 原提示词，数值分支采用在原模板上加入单位处理和 5% 相对误差的提示词。三组均使用 deepseek-v4-flash，不输入图像。

| 模型 / 推理配置 | 规则评分 | 混合评分 | 所有错题 API 复判 |
|---|---:|---:|---:|
| Qwen3 base | 81.28% | 83.48% | 84.32% |
| Old step80 | 76.96% | 79.32% | 89.36% |
| New step80 | 80.24% | 82.12% | 89.48% |

| 模型 | Human API 复判 | Augmented API 复判 | 总体答对 / 2500 |
|---|---:|---:|---:|
| Qwen3 base | 74.88% | 93.76% | 2108 |
| Old step80 | 84.08% | 94.64% | 2234 |
| New step80 | 83.84% | 95.12% | 2237 |

新 step80 比本地底座高 5.16 个百分点；比旧 step80 高 0.12 个百分点，即 3 题。规则分中新旧相差 3.28 个百分点，API 复判后差距明显缩小。
本地底座为 2026-09-22 保存的 Qwen3-VL-8B-Instruct 直答结果；新旧 step80 为 Agent 工具推理。该比较包含推理配置差异，不能把相对底座的差异单独归因于训练。

## 完整性与协议例外

三组都是相同的 2500 个题号、问题与参考答案。旧 step80 原规则正确 1924 题，非数值 API 新接受 59 题，数值 API 新接受 251 题，总计 2234 题。旧 step80 共 585 个唯一请求，1 次截断后按原参数重试成功，无残留失败。
底座原规则正确 2032 题，非数值 API 新接受 55 题，数值 API 新接受 21 题，总计 2108 题。底座 #749 在 1024 token 上限下两次截断，仅该请求重试提高为 2048；提示词、模型和其他参数不变。
原始评测文件均未修改；各次判定、回复、输入哈希与参数均保存在各自目录。

## API 判定波动检查

以下检查仅比较相同提示词且输出 token 上限相同的重复请求，保留各次实际结果，没有事后挑选判定：
| 两组 | 完全相同请求数 | 判定不一致数 |
|---|---:|---:|
| Qwen3 base vs Old step80 | 124 | 3 |
| Qwen3 base vs New step80 | 118 | 3 |
| Old step80 vs New step80 | 399 | 7 |

本结果是自定义 API 复判成绩，不是 ChartQA 官方规则成绩，也不是逐行复现 DeepEyesV2。少量分差需结合重复判定波动看待，不宜据此主张稳定提升。
